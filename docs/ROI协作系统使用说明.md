# ROI 协作系统使用说明

## 1. 目标

通过统一数据口径和预测模型，帮助财务与投放对齐 ROI 目标，并对单个投放批次形成一致决策。

流程：

`统一口径 → 历史拟合 → 标准反推 → D7 预测 → 放量/观察/止损 → 投后复盘`

## 2. 角色分工

- **财务**：确定目标 ROI、目标周期、预算上限和风险底线。
- **投放**：创建批次、录入真实数据并执行投放动作。
- **系统**：拟合历史规律、预测目标日 ROI、说明风险并给出行动建议。

## 3. 投前

### 3.1 拟合历史曲线

1. 财务与投放先统一 ROI、收入、成本和归因口径。
2. 按场景选择历史批次，进入“预估曲线拟合”。
3. 导入或录入数据，完成拟合并保存模型包。
4. 检查有效模型、回测误差和模型分歧。

拉新与拉活、新渠道与老渠道原则上分别建立模型包，不能混合拟合。

### 3.2 反推标准组合

1. 进入“考核标准反推”。
2. 选择对应模型包，输入目标 ROI 和目标周期。
3. 获取 D1 ROI、D7 ROI、次留、7 留联合标准。

四项指标必须作为完整组合使用。反推标准用于投前参考，不作为单指标硬性淘汰线。

### 3.3 确认正式版本

双方共同确认并记录：模型包、目标 ROI、目标周期、预算边界、适用场景和生效时间。实际结果产生后不能临时修改标准。

## 4. 投中

### 4.1 D1–D6

主要监控成本、归因和数据异常，不做正式长期 ROI 判断。明显超出亏损或预算边界时可以提前止损。

### 4.2 D7 首次正式预测

投放累计至少 7 天后，录入实际数据：

- D1 ROI；
- D7 ROI；
- 次留；
- 7 留；
- 当前累计投入。

进入“ROI 预估”，选择投前确认的模型包和目标，查看目标日 ROI、首次达标日、模型分歧和风险提示。

### 4.3 决策规则

| 建议 | 判断 | 默认动作 |
|---|---|---|
| 放量 | 保守综合值达标，模型分歧和数据风险可接受 | 在预算上限内增加投入 |
| 观察 | 接近目标、数据不足、模型分歧较大或属于外推 | 维持投入并指定下一复核日 |
| 止损 | 保守综合值明显不达标，且多数模型判断一致 | 暂停新增预算或收缩投入 |

每项建议必须说明预测 ROI、目标差距、主要指标表现、模型一致性和下一步动作。

超预算、低置信度、历史范围外预测或人工覆盖系统建议时，由财务与投放共同确认并记录原因。

## 5. 投后

1. 在 D15、D30 等关键节点补充实际数据并重新预测。
2. 目标周期结束后记录最终 ROI。
3. 对比预测、实际动作和最终结果。
4. 统计预测误差、错杀率和误放率，定期更新模型及标准版本。

## 6. 场景差异

| 场景 | 使用方式 |
|---|---|
| 老渠道 × 拉新 | 使用本渠道成熟历史；预算上限内可直接放量 |
| 新渠道 × 拉新 | 先设置探索预算，积累数据后再开放正式放量 |
| 老渠道 × 拉活 | 单独建模，ROI 应优先使用扣除自然回流后的增量收入 |
| 新渠道 × 拉活 | 优先采用实验组与对照组，先验证增量效果 |

## 7. 当前能力边界

当前工具已经支持：

- 多批次历史拟合和模型包保存；
- D1 ROI、D7 ROI、次留、7 留联合反推；
- 新批次实际数据录入；
- 目标日 ROI、首次达标日、模型分歧和风险提示。

当前尚未支持：

- 自动输出放量、观察或止损；
- 场景强制隔离和预算权限；
- 多人共享、审批及版本留痕；
- 自动历史回放、错杀率和误放率报表。

现阶段可验证“历史拟合—标准反推—D7 预测”的核心流程，三级决策仍需双方依据预测结果共同完成。
